Supabase

1. Crie um projeto no Supabase.
2. No SQL Editor, rode o conteúdo de `supabase/migrations/001_init.sql`.
3. Crie políticas RLS para tabelas sensíveis (users/holdings/alerts) e configure autenticação.
4. Adicione as variáveis de ambiente no Vercel/GitHub Actions: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, NEXT_PUBLIC_SUPABASE_ANON_KEY.
