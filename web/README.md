# Web (Next.js) — Análise e Gestão de FIIs

Rodando localmente:

1. cd web
2. npm install
3. Copie `.env.example` para `.env.local` e preencha as variáveis
4. npm run dev

Variáveis de ambiente (ver `.env.example`):
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY

Autenticação e integração com Supabase: usar `@supabase/supabase-js` e RLS do Supabase.
